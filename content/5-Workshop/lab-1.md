# Cloud Infrastructure Lab

## Objective
Implement best practices for AWS Infrastructure.

## Environment
- VPC, Subnets, EC2, IAM Roles

## Implementation steps
1. Deploy base infrastructure using CloudFormation.
2. Configure security groups and NACLs.
3. Verify connectivity and access.

## Result
A fully functional and secure environment.

## Lessons learned
Always apply the principle of least privilege.
